# About this book

AI4Econ is an open, short tutorial about using AI to produce and assess research data for economics. Its first edition focuses on text annotation because it makes the key decisions visible: the unit of analysis, evidence, disagreement, error, and the boundary between measurement and inference.

The example sentences and numbers in the chapters are illustrative. They are not empirical findings. Adapt the task definition and evaluation design before applying the workflow to a real corpus.

The source is available in the [GitHub repository](https://github.com/luzhiyu-econ/AI4Econ). To suggest a correction, open an issue or use the “Edit this page” link on the relevant chapter.
